# neo-pkg-llm-chat v4.0.2

[English](README.md) | [한국어](README.kr.md) | [日本語](README.ja.md)

Machbase Neo의 시계열 데이터를 자연어로 조회하고 분석하는 LLM 채팅 패키지입니다.

## 개요

neo-pkg-llm-chat은 Machbase Neo의 시계열 데이터를 자연어로 조회하고 분석할 수 있는 LLM 기반 채팅 인터페이스입니다.

웹 브라우저에서 질문하면 LLM 에이전트가 Machbase Neo에 저장된 데이터를 직접 조회하고 분석합니다.  
SQL을 작성하지 않고도 테이블 탐색, 태그 목록 확인, 데이터 분석, 대시보드와 리포트 생성까지 하나의 대화로 할 수 있습니다.

## 누구를 위한 패키지인가요?

- **데이터 입문자** — SQL 없이 자연어로 데이터를 살펴보고 이해합니다
- **데이터 엔지니어** — 복잡한 쿼리를 작성하지 않고 데이터를 빠르게 검증·분석·시각화합니다

## 주요 기능

- **여러 LLM 프로바이더** — Claude, ChatGPT, Gemini, Ollama(로컬) 중에서 자유롭게 선택하고 전환
- **Machbase 직접 연동** — LLM이 테이블·태그·시계열 데이터를 직접 조회하고 분석
- **채팅으로 대시보드·리포트 생성** — 대화로 분석 대시보드와 리포트 생성
- **웹 기반 설정** — API 키, 모델, 데이터베이스 연결을 브라우저에서 간단히 설정

## 예시 질문

- "테이블 목록 보여줘"
- "Rollup이 뭐야?"
- "Example 테이블 분석 대시보드 만들어줘"
- "Example 테이블 재무 분석 리포트 작성해줘"
- "Example 테이블 진동 분석 리포트 작성해줘"
