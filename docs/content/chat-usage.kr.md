## 모델 선택

Chat 화면 아래쪽의 **Select model** 버튼을 눌러 사용할 모델을 고릅니다.

- Provider별로 등록된 모델 목록이 표시됩니다.
- 선택한 모델은 `provider / model` 형식으로 보입니다.
- 모델을 선택하지 않으면 질문을 보낼 수 없습니다.

## 연결 상태

입력창 아래에는 연결 상태가 표시됩니다.

- `Connected`
  - 서버와 정상 연결된 상태
- `Disconnected`
  - 연결이 끊긴 상태

연결이 끊겼을 때는 **Reconnect** 버튼으로 다시 연결을 시도할 수 있습니다.

## 질문 보내기

1. 모델을 선택합니다.
2. 입력창에 질문을 씁니다.
3. 전송 버튼을 누릅니다.

모델을 선택한 뒤 빈 화면에서는 추천 질문 칩이 보일 수 있습니다.  
이 칩을 누르면 예시 질문이 입력창에 채워집니다.

예:

- 어떤 테이블이 있어?
- 태그 목록 보여줘
- 분석 대시보드 만들어줘
- 분석 리포트 작성해줘

![추천 질문 칩 화면](/images/llm-chat-suggestions.png)

## 즐겨찾기 (자주 쓰는 질문)

입력 영역 옆의 **즐겨찾기** 버튼을 누르면 자주 쓰는 질문을 저장해 두는 패널이 열립니다.

- 패널 입력창에 질문을 적고 Enter를 누르면 즐겨찾기에 추가됩니다.
- 저장된 항목을 클릭하면 그 질문이 입력창에 채워집니다.
- 항목은 드래그로 순서를 바꿀 수 있고, 각 항목에서 삭제할 수 있습니다.
- 이미 있는 질문을 다시 추가하려 하면 새로 만들지 않고 기존 항목을 강조해 알려줍니다.

즐겨찾기는 API 토큰 계정별로 서버에 저장되어(다른 기기에서도 유지) 계정마다 분리됩니다. 서버에 저장할 수 없을 때(토큰 없음, 서비스 연결 끊김)는 브라우저 로컬 저장소에 임시 보관됩니다.

## 자동 모드 전환

질문 내용에 따라 내부 실행 흐름이 자동으로 정해집니다.

- "리포트", "보고서", "report"
  - HTML 리포트를 만듭니다.
- "심층", "고급", "FFT", "RMS", "스펙트럼", "이상 탐지" 등
  - 분석 의도(IR)로 컴파일한 심층 차트를 만드는 고급 분석 흐름을 씁니다.
- 차트·대시보드·분석 요청
  - 테이블 기반 차트를 만드는 기본 분석 흐름을 씁니다.
- 테이블·태그를 지목한 조회, "평균", "최근", "몇 건", "온도 몇 도야" 같은 수치 질문
  - SQL로 조회해 답합니다.
- "뭐야", "어떻게", "예제" 같은 개념·사용법 질문
  - 매뉴얼 문서를 찾아 답합니다.

## 시각 표시

조회 결과, 차트, 리포트의 시각은 **브라우저의 시간대**로 표시됩니다. 다른 시간대로 보려면 질문에 "UTC 기준으로"처럼 적습니다.

질문 속 날짜("어제", "2025년 3월")는 Neo 서버의 시간대로 해석합니다.

## 답변 끝의 "※ 적용 기준"

요청한 단위·기간·태그로는 차트를 그릴 수 없으면 도구가 값을 조정합니다(예: 6개월 기간을 1분 단위로 요청하면 1일 단위로 올림). 로컬 모델(Ollama)의 답변에 조정된 값이 빠지면 답변 끝에 한 줄이 붙습니다.

```text
※ 적용 기준: 일 단위 · 기간 2025-09-21 ~ 2026-03-23
```

모델이 답변에 이미 그 값을 적었으면 붙지 않습니다.

## 응답 생성 중 동작

응답 생성 중에는 전송 버튼 대신 **Stop** 버튼이 표시됩니다.

- 응답을 중단하고 싶으면 Stop 버튼을 누릅니다.
- 생성이 끝나면 일반 전송 버튼으로 돌아옵니다.

## 대화 지우기

대화가 쌓인 뒤에는 화면 오른쪽 위의 **Clear session** 버튼으로 현재 세션을 비울 수 있습니다.

이 동작은 현재 대화 세션을 정리하는 용도입니다.

## Settings로 돌아가기

입력 영역 오른쪽 아래의 Settings 버튼을 누르면 설정 화면으로 이동합니다.

다음 경우에 주로 사용합니다.

- 다른 Provider API Key를 추가할 때
- Model을 새로 등록할 때
- Machbase 연결 정보를 바꿀 때

## 대표 요청 예시

- 테이블 목록 조회
  - "테이블 리스트 조회 해줘"
- 태그 목록 조회
  - "Example 테이블의 태그 리스트 조회해줘"
- 문서 탐색
  - "Rollup 이 뭐야?"
- 대시보드 생성
  - "Example 테이블 데이터의 분석 대시보드 만들어줘"
- 심층 대시보드 생성
  - "Example 테이블 데이터의 심층 분석 대시보드 만들어줘"
- 분석 리포트 생성
  - "Example 테이블 데이터 분석 리포트 작성해줘"

## 사용 팁

- 처음에는 간단한 조회 질문으로 시작합니다.
- 대시보드나 리포트 요청은 테이블 이름을 명확히 포함하는 편이 좋습니다.
- 모델이 여러 개라면 빠른 질의용과 정밀 분석용을 나누어 등록하면 편리합니다.
