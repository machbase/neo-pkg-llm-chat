バージョンごとの主な変更点と更新方法を案内します。

## 更新方法

| 使用中のバージョン | 更新方法 | 更新後に行うこと |
| :--- | :--- | :--- |
| 4.0.0 ～ 4.0.1 | パッケージ一覧から更新 | なし |
| 2.0.0 ～ 3.3.1 | パッケージ一覧から更新 | SettingsでAPIトークンを登録（[初期設定]({{< relref "first-setup" >}})を参照） |
| 1.0.x | パッケージを削除してから再インストール | Settingsをすべて入力し直す |

- Machbase Neo 8.7.3以上が必要 — 更新前にNeoのバージョンを確認
- 既存の設定（プロバイダー、モデル、接続情報）とお気に入りは更新後も保持
- 更新中の数秒間はチャットが切断 — 進行中の回答は中断
- 4.0.1以前から更新した後も画面が変わらない場合は、LLM Chat画面の中で右クリック → **フレームを再読み込み** — 接続アドレス（`127.0.0.1`、`192.168.x.x`など）ごとに必要
- 1.0.xは更新ではなく再インストール — 内部構造が異なるため

## 4.0.2（2026-11-06）

- Settings画面に**トークンの発行方法**の案内（手順ごとの図）を追加
- **更新後の画面の自動更新**：次回の更新から、古い画面が残っていれば新しいバージョンで自動的に開き直す
- **ドキュメントの改善**
  - READMEの韓国語版・日本語版を追加
  - マニュアルの目次に各ドキュメントの内容の案内を追加

## 4.0.1（2026-11-03）

- **ダッシュボード作成の安定化**：高度な分析ダッシュボードの作成が途中で止まる問題を改善
- **閉域網への対応**：インターネットに接続していなくても画面を正しく表示
- **インストール・更新の安定化**
  - 更新後に以前のバージョンのファイルを整理
  - サービスが重複して実行される問題を修正
- **リリースノート**を追加
- パッケージアイコンを変更

## 4.0.0（2026-10-26）

- **APIトークン認証**
  - Neoコンソールのログインの代わりに、アカウントごとのAPIトークンで接続
  - データの照会もトークンのアカウントの権限で実行
- **タイムゾーンの反映**：レポート・照会結果・チャートの時刻をブラウザのタイムゾーン基準で表示
- **回答の改善**：Ollamaモデルの回答に、実際に適用した照会条件（単位・期間・タグ）を併せて表示
- **セキュリティチェックの改善**
  - データの変更・削除の指示はブロック
  - 関連する質問には回答
- **日本語ドキュメント**を追加
- **タイマー機能の削除**
  - チャットでNeoのタイマーを作成する機能を削除
  - タイマーに関する質問にはマニュアルを案内
- 必要な最小Neoバージョンを8.7.3に変更
