## モデルの選択

Chat画面下部の**Select model**ボタンを押して、使用するモデルを選びます。

- プロバイダーごとに、登録されたモデルの一覧が表示されます。
- 選択したモデルは`provider / model`の形式で表示されます。
- モデルを選択しないと、質問を送信できません。

## 接続状態

入力欄の下に接続状態が表示されます。

- `Connected`
  - サーバーと正常に接続されている状態
- `Disconnected`
  - 接続が切れている状態

接続が切れたときは、**Reconnect**ボタンで再接続を試みることができます。

## 質問の送信

1. モデルを選択します。
2. 入力欄に質問を書きます。
3. 送信ボタンを押します。

モデルを選択した後、会話が空の画面では推奨質問のチップが表示されることがあります。  
このチップを押すと、例の質問が入力欄に入力されます。

例：

- 어떤 테이블이 있어?（どんなテーブルがある？）
- 태그 목록 보여줘（タグ一覧を見せて）
- 분석 대시보드 만들어줘（分析ダッシュボードを作って）
- 분석 리포트 작성해줘（分析レポートを書いて）

## お気に入り（よく使う質問）

入力エリアの横にある**즐겨찾기**（お気に入り）ボタンを押すと、よく使う質問を保存しておくパネルが開きます。

- パネルの入力欄に質問を書いてEnterを押すと、お気に入りに追加されます。
- 保存された項目をクリックすると、その質問が入力欄に入力されます。
- 項目はドラッグで順序を変更でき、各項目から削除できます。
- すでにある質問をもう一度追加しようとすると、新しく作成せず、既存の項目を強調表示して知らせます。

お気に入りはAPIトークンのアカウントごとにサーバーに保存され（別の端末でも保持されます）、アカウントごとに分離されます。サーバーに保存できないとき（トークンがない、サービスとの接続が切れている）は、ブラウザのローカルストレージに一時的に保管されます。

## 自動モード切り替え

質問の内容によって、内部の実行フローが自動的に決まります。

- 「리포트」、「보고서」、「report」
  - HTMLレポートを作成します。
- 「심층」、「고급」、「FFT」、「RMS」、「스펙트럼」、「이상 탐지」など
  - 分析意図（IR）からコンパイルした詳細チャートを作成する詳細分析のフローを使用します。
- チャート・ダッシュボード・分析の依頼
  - テーブルベースのチャートを作成する基本分析のフローを使用します。
- テーブル・タグを指定した照会、「평균」、「최근」、「몇 건」、「온도 몇 도야」（温度は何度？）のような数値の質問
  - SQLで照会して回答します。
- 「뭐야」、「어떻게」、「예제」、「what is」、「how to」のような概念・使い方の質問
  - マニュアル文書を探して回答します。

> モード判定のキーワードは英語と韓国語のみ認識します。日本語で質問する場合も、レポートや詳細分析を依頼するときは`report`・`FFT`などの英語キーワードを含めてください。

## 時刻の表示

照会結果、チャート、レポートの時刻は**ブラウザのタイムゾーン**で表示されます。別のタイムゾーンで見たい場合は、質問に「in UTC」のように書きます。

質問中の日付（「yesterday」、「March 2025」）は、Neoサーバーのタイムゾーンで解釈します。

## 回答末尾の「※ 적용 기준」（適用基準）

依頼された単位・期間・タグではチャートを描けない場合、ツールが値を調整します（例：6か月の期間を1分単位で依頼すると1日単位に引き上げ）。ローカルモデル（Ollama）の回答に調整後の値が抜けている場合、回答の末尾に1行が付きます。

```text
※ 적용 기준: 일 단위 · 기간 2025-09-21 ~ 2026-03-23
```

モデルがすでに回答にその値を書いている場合は付きません。

## 応答生成中の動作

応答の生成中は、送信ボタンの代わりに**Stop**ボタンが表示されます。

- 応答を中断したいときは、Stopボタンを押します。
- 生成が終わると、通常の送信ボタンに戻ります。

## 会話の消去

会話が溜まった後は、画面右上の**Clear session**ボタンで現在のセッションを空にできます。

この操作は、現在の会話セッションを整理するためのものです。

## Settingsに戻る

入力エリアの右下にあるSettingsボタンを押すと、設定画面に移動します。

主に次の場合に使用します。

- 別のプロバイダーのAPI Keyを追加するとき
- モデルを新しく登録するとき
- Machbaseの接続情報を変更するとき

## 代表的な依頼の例

- テーブル一覧の照会
  - "Show me the table list"
- タグ一覧の照会
  - "Show me the tag list for the Example table"
- ドキュメントの検索
  - "What is Rollup?"
- ダッシュボードの作成
  - "Create an analysis dashboard for the Example table data"
- 詳細分析ダッシュボードの作成
  - "Create an advanced analysis dashboard for the Example table data"
- 分析レポートの作成
  - "Write an analysis report for the Example table data"

## 使用のヒント

- 最初は簡単な照会の質問から始めます。
- ダッシュボードやレポートを依頼するときは、テーブル名を明確に含めることをおすすめします。
- モデルが複数ある場合は、素早い照会用と精密な分析用に分けて登録すると便利です。
