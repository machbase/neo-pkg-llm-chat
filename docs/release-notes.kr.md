# 릴리스 노트

<p align="center" style="margin-top:1.25rem"><strong>한국어</strong> | <a href="./release-notes.en.md">English</a> | <a href="./release-notes.ja.md">日本語</a></p>

버전별 주요 변경 사항과 업데이트 방법을 안내합니다.

## 업데이트 방법

| 사용 중인 버전 | 업데이트 방법 | 업데이트 후 할 일 |
| :--- | :--- | :--- |
| 4.0.0 | 패키지 목록에서 업데이트 | 없음 |
| 2.0.0 ~ 3.3.1 | 패키지 목록에서 업데이트 | Settings에서 API 토큰 등록 ([첫 설정](./first-setup.kr.md) 참고) |
| 1.0.x | 패키지를 제거한 뒤 다시 설치 | Settings 전체 다시 입력 |

- Machbase Neo 8.7.3 이상이 필요합니다. 업데이트 전에 Neo 버전을 확인합니다.
- 기존 설정(Provider, 모델, 연결 정보)과 즐겨찾기는 그대로 유지됩니다.
- 업데이트하는 몇 초 동안 채팅이 끊기며, 진행 중이던 답변은 중단됩니다.
- 업데이트가 끝나면 열려 있던 LLM Chat 화면을 새로 고칩니다.
- 1.0.x는 내부 구조가 달라 업데이트 대신 다시 설치해야 합니다.

## 4.0.1 (2026-11-03)

- **대시보드 생성 안정화**: 고급 분석 대시보드를 만들다 멈추는 경우를 보완했습니다.
- **폐쇄망 지원**: 인터넷 연결 없이도 화면이 정상 표시됩니다.
- **설치·업데이트 안정화**: 업데이트 후 이전 버전 파일을 정리하고, 서비스가 중복 실행되지 않습니다.
- **릴리스 노트** 문서 추가
- 패키지 아이콘 변경

## 4.0.0 (2026-10-26)

- **API 토큰 인증**: Neo 콘솔 로그인 대신 계정별 API 토큰으로 연결합니다. 데이터 조회도 토큰 계정의 권한으로 실행됩니다.
- **시간대 반영**: 리포트, 조회 결과, 차트의 시각을 브라우저 시간대 기준으로 표시합니다.
- **답변 개선**: Ollama 모델의 답변에 실제 적용한 조회 기준(단위·기간·태그)을 함께 표시합니다.
- **보안 검사 개선**: 데이터 변경·삭제 지시는 차단하고, 관련 질문에는 답합니다.
- **일본어 문서** 추가
- **타이머 기능 제거**: 채팅으로 Neo 타이머를 만드는 기능을 제거했습니다. 타이머 관련 질문에는 매뉴얼을 안내합니다.
- 필요한 최소 Neo 버전을 8.7.3으로 변경
