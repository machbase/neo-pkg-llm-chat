# 문제 해결

<p align="center" style="margin-top:1.25rem"><strong>한국어</strong> | <a href="./troubleshooting.en.md">English</a> | <a href="./troubleshooting.ja.md">日本語</a></p>

## 저장이 되지 않음

다음 항목을 확인합니다.

- Machbase `Host`, `Port`, `API Token`
- API 토큰 검증 결과가 `✓`인지 (아래 "토큰 검증이 실패함" 참고)
- 추가한 Model의 `Display Name`, `Model ID`
- 실제로 사용할 수 있는 Provider가 하나 이상 등록되었는지

입력이 빠지면 저장 시 오류 안내가 표시됩니다.

## 토큰 검증이 실패함

| 결과 표시 | 원인 | 조치 |
| :--- | :--- | :--- |
| `✗ 유효하지 않은 토큰입니다` | 토큰을 잘못 복사했거나, Neo에서 삭제·만료된 토큰 | 토큰을 다시 복사하거나 Neo 콘솔에서 새로 발급 |
| `✗ 콘솔 로그인 계정(…)과 다른 계정(…)의 토큰입니다` | 콘솔에 로그인한 계정과 토큰 계정이 다름 | 콘솔 로그인 계정의 토큰을 입력하거나, 그 토큰 계정으로 콘솔에 다시 로그인 |
| `✗ Neo 콘솔 로그인 정보를 확인할 수 없습니다` | 콘솔에 로그인되어 있지 않음 | 콘솔에 로그인한 뒤 LLM Chat을 다시 열기 |
| `✗ 검증 실패: …` | LLM Chat 서비스에 연결할 수 없음 | 패키지 서비스가 실행 중인지 확인 |

## 앱을 열었더니 "저장된 API 토큰을 사용할 수 없습니다"가 표시됨

- 브라우저에 저장해 둔 토큰이 Neo에서 삭제되었거나 만료된 경우입니다.
- Settings 화면에서 새 토큰을 입력하고 **검증** 후 **Save**를 누릅니다.

## 채팅에 "API 토큰이 확인되지 않았습니다"가 표시됨

- 사용 중 토큰이 삭제되었거나 만료된 경우입니다.
- Settings 화면에서 새 토큰을 입력하고 검증·저장한 뒤 다시 질문합니다.

## 다른 PC나 브라우저에서 토큰을 다시 입력하라고 함

- 정상 동작입니다. 토큰은 브라우저별, 콘솔 계정별로 저장됩니다.
- 같은 계정의 토큰을 입력하고 검증하면 서버에 저장된 기존 설정(Provider, 모델)을 불러옵니다.
- 접속 주소가 바뀌어도(`127.0.0.1` ↔ `192.168.x.x`) 브라우저는 다른 저장소로 취급하므로 다시 입력해야 합니다.

## 리포트 링크가 열리지 않음

- 채팅 화면의 리포트 링크는 저장된 API 토큰으로 파일을 받아 새 창에 표시합니다.
- "API 토큰이 유효하지 않습니다"가 표시되면 Settings에서 토큰을 확인합니다.
- 링크 주소를 복사해 브라우저 주소창에 직접 열면 Neo가 토큰 인증을 요구하므로 열리지 않습니다(`401`). 채팅 화면의 링크를 눌러 엽니다.

## 타이머를 만들어 달라고 했는데 등록되지 않음

- LLM Chat은 타이머 등록·시작·중지·삭제·목록 조회를 지원하지 않습니다.
- 타이머 관련 질문에는 매뉴얼을 근거로 등록 방법(웹 콘솔 Timer 메뉴, 셸 `timer` 명령)과 TQL 예시를 안내합니다.
- 타이머 등록과 관리는 Neo 웹 콘솔의 Timer 메뉴나 셸에서 직접 합니다.

## 모델 목록이 비어 있음

- 이 계정의 설정을 아직 저장하지 않았으면 목록이 비어 있습니다. Settings에서 Save를 누릅니다.
- Settings에서 Model을 실제로 추가했는지 확인합니다.
- 해당 Provider의 API Key 또는 Ollama URL이 맞는지 확인합니다.
- Chat 화면에서 모델 목록을 다시 열어 새로고침합니다.

## Chat 화면이 Disconnected 상태임

- 서버 연결이 일시적으로 끊긴 경우일 수 있습니다.
- `Reconnect` 버튼으로 다시 연결합니다.
- 계속 실패하면 패키지 서비스 상태와 브라우저 네트워크 상태를 함께 확인합니다.

## 질문은 보냈는데 응답이 늦음

가능한 원인:

- 선택한 모델 자체가 느린 경우
- 외부 Provider 응답이 느린 경우
- Machbase 질의나 대시보드 생성 작업이 오래 걸리는 경우

이때는 잠시 기다리거나 필요하면 **Stop**으로 중단 후 질문을 더 단순하게 바꿔 다시 시도합니다.

## 원하는 답이 나오지 않음

- 테이블 이름을 정확히 넣어 질문합니다.
- 기간, 태그, 컬럼 이름을 함께 적으면 결과가 더 안정적입니다.
- “대시보드”, “리포트”, “태그 목록”처럼 목적을 분명하게 적는 편이 좋습니다.
- 로컬 모델(Ollama)은 한 질문에서 SQL을 8번까지 실행합니다. 조회가 많이 필요한 질문은 나눠서 묻습니다.

## 대시보드를 고쳐 달라고 했는데 새 대시보드가 만들어짐

- 현재 버전은 대화로 기존 대시보드를 수정(차트 추가·삭제, 기간 변경 등)하는 기능을 지원하지 않습니다.
- 대시보드 수정은 Neo 웹 콘솔의 대시보드 화면에서 합니다.

## 시각이 예상과 다르게 보임

- 조회 결과·차트·리포트의 시각은 브라우저 시간대 기준입니다.
- 다른 시간대가 필요하면 질문에 "UTC 기준으로"처럼 적습니다.
- 질문 속 날짜("어제", "2025년 3월")는 Neo 서버의 시간대로 해석합니다. 브라우저와 서버의 시간대가 다르면 기간 경계가 어긋날 수 있습니다.

## 운영 권장 사항

- 처음에는 Provider 1개, Model 1개만 등록해 동작을 확인합니다.
- Machbase 연결 정보가 바뀌거나 토큰을 새로 발급하면 Settings에서 즉시 수정합니다.
- 여러 모델을 쓸 경우 Display Name을 구분하기 쉽게 정리합니다.
